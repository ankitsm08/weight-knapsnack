Weight Knapsnack

Wanna exercise? Get your Bags and Bottles ready.

Features

Flexible input parsing (kg, g, lb) with smart conversions
Persistent bag weight and bottle data with local storage
Dynamic bottle table editor (add, edit, remove) with defaults
Optimized dynamic programming algorithm for instant results
Smart bottle combo selection with penalty and overshoot control
Clean tabular output (weights, counts, diffs) up to 3 decimals
Runs entirely in browser - no server required
